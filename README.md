# KiCad Water Distribution System

Industrial-grade AI-Monitored Automated Water Distribution System for agriculture

## Project Overview
This is a complete KiCad 9 PCB design project for an agricultural water distribution system with:
- ESP32-WROOM-32E microcontroller
- 8 capacitive soil moisture sensors
- 9 outputs (1 pump + 8 solenoid valves)
- RS485 communication
- Advanced power management
- Manufacturing-ready for LionCircuits

## Files
- `.kicad_pro` - KiCad project file
- `.kicad_sch` - Schematic
- `.kicad_pcb` - PCB layout
- `BOM.csv` - Bill of Materials
- `gerber/` - Manufacturing Gerber files

## Specifications
- 4-layer PCB: 150mm x 120mm
- FR4, 1.6mm thickness, 1oz copper, ENIG finish
- ERC and DRC clean design
- Ready for manufacturing
